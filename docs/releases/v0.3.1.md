# 笔键联动 v0.3.1 · 首次公开预发布版

用 OPPO Pencil 3 的操作键，在抖音和不背单词中完成常用操作。

## 功能

- **抖音单击**：短按一次切到下一个视频，上滑手势时长 120 ms。
- **抖音双击**：快速短按两次发送视频双击点赞手势，不切视频。第二次按下后暂停待定上滑，修复早期双击变成连续切视频的问题。
- **可调节奏**：默认识别窗口 450 ms，可调 250–800 ms；单击会等待窗口结束。
- **不背单词**：短按优先点击“认识”，页面没有“认识”时查找“下一个”，每次只执行一步。
- **设置页面**：浅雾蓝配色、首页与四个子菜单、按键录入、动作测试、包名及按钮文字配置、坐标备用方案。
- **自定义图标**：采用项目发起者提供的命令键与斜置触控笔图片。

## 环境与反馈

项目发起者报告的实机环境：**OPPO Pad Mini + OPPO Pencil 3，ColorOS 17.0 / Android 17**。系统版本由用户提供，未通过工具读取核实。用户已确认抖音双击点赞及不背单词操作可用，早期测试也反馈短按可切视频。未测试其他设备、系统或第三方应用版本。

清单最低安装要求是 Android 8.0 / API 26；compileSdk 和 targetSdk 均为 35，这是构建配置，与用户报告的 Android 17 实机系统不同。

## 安装

下载附件 `PencilLink-0.3.1.apk`，传到平板安装。APK 已签名，沿用此前测试版签名，可覆盖旧版。首次使用进入“连接与按键”，阅读权限说明、开启无障碍服务，再录入笔键；回首页打开联动总开关。

升级后服务若无响应，关闭并重新开启无障碍服务。若双击仍识别不稳，在“抖音”子菜单将识别窗口调到 600–800 ms。

## 已知限制

- 依赖系统转发按键，不能保证其他设备或版本一定开放手写笔按键。
- 仅按包名限制操作范围，未自动识别抖音全屏视频页；请勿在评论、搜索或私信页按键。
- 不背单词按钮文字必须精确匹配；显示“下一词”等文字时应修改设置。
- 坐标备用方案仅保存一个位置，不能自动判断页面；按钮位置不同或布局变化时可能误点。
- 这是早期预发布版，无 OPPO、抖音或不背单词官方关联。当前使用本地测试证书，签名私钥不随源码分发。
